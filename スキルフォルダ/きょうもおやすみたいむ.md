# 和風Git自動連携スキル (Wafu Git Workflow Skill)

## 概要
このスキルは、作業ブランチで行った変更をコミットし、`main` ブランチへ統合してからリモートへプッシュする一連のGitワークフローを規定するものです。

## 実行条件・手順

### 1. コミットの実行と和風メッセージの付与
- `git status` を確認し、ローカルに未実行の変更（コミットされていない差分）があれば `git add .` および `git commit` を行う。
- **コミットメッセージの厳格なルール**:
  - 表題（1行目）は、**「和風でウイット（機知）に富んだ風流なコメント」** にすること。（例：「秋風にバグの葉散る夕暮れかな」「いとをかし、設定ファイルの衣替え」など）
  - 表題の後に空行を挟み、具体的な修正内容の概要を箇条書きなどで記載すること。

### 2. 作業報告書の作成と追加コミット（記録の編纂）
- 一連の作業内容のコミットが完了後、**「作業報告書作成」（`作業報告書作成.md`）のスキルを実行**し、本日の作業履歴を報告書として出力する。
- 報告書が作成されたら、そのファイルを再度ステージングし、「本日の作業報告書を提出仕り候」などの和風コメントで追加のコミットを行う。

### 3. mainブランチへのマージ
- 作業中のローカルブランチ名を記録する。
- ローカルの `main` ブランチへ切り替える (`git checkout main`)。
- 記録した作業ブランチを `main` ブランチへマージする (`git merge <作業ブランチ>`)。

### 4. リモートへのPushと競合解決（自軍優先の陣立て）
- ローカルでのマージ完了後、リモートリポジトリへPushを実行する (`git push origin main`)。
- 万が一Push時に他の変更とのコンフリクト（競合）が発生して拒否された場合は、**「自分の修正を優先してPushする」** というルールの元、強制プッシュ（`git push -f origin main`）を実行し、己の変更を正とする。
