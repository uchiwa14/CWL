# かわいいコミット (Cute Commit Skill)

## 概要
このスキルは、Gitコミットを行う際に、表題（1行目）を「とてもキュートなメッセージ」にし、詳細（2行目以降）を「修正内容がはっきりわかる詳細なメッセージ」にするためのスクリプトです。

## 実行条件・手順

### 1. 変更のステージング
- `git add <対象ファイル>` などを用いて、コミットしたい変更をステージングする。
- ユーザーにステージング済みのファイルがあるか確認し、無ければ `git status` の結果を提示して、どのファイルをステージングするか尋ねる。

### 2. コミットメッセージの生成
- ステージングされた変更内容から、詳細な修正内容を把握する。
- 以下の2つの要素を含んだコミットメッセージを生成する。
  1. **表題（1行目）**: 変更内容に関連した、絵文字を用いたとてもキュートなメッセージ。（例: `✨ 準備バッチリ！朝の支度がもっとスムーズになったよ♪`）
  2. **詳細（2行目以降）**: 実際に何を変更したのか、技術的・具体的に分かりやすく書いたメッセージ。

### 3. コミットの実行
- ターミナルから、生成したメッセージを用いてコミットを実行する。
- **実行コマンド例**: `git commit -m "<表題>" -m "<詳細>"`

### 4. 実行後の報告
- コミットが成功した旨と、実際に使用したコミットメッセージをユーザーに報告する。
